# context-wikis

A context wiki is a git-tracked bundle of interlinked markdown that
accumulates knowledge across projects, maintained by human and agent
together. It is wrong when it disagrees with the world -- unlike a `docs/`
file, which is wrong when it disagrees with the code.

Wikis are shareable and they layer: an agent can consult a personal wiki and
a company one in the same session.

## Status

**Not yet written.** Both skills below exist as empty files, so installing
this plugin currently gives you nothing. The conventions are decided but
unencoded; they are recorded in the `starting-from-handover` work item under
this repository's [docs/dev/work/](../../docs/dev/work/).

## Skills

- `context-wikis` -- the wiki layout and its conventions.
- `open-knowledge-format` -- the markdown conventions a wiki follows, OKF.
